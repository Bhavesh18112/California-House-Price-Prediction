# 🏠 California House Price Prediction

A Machine Learning project that predicts California house prices using the Scikit-learn California Housing Dataset.

---

## 📌 Project Overview

This project uses a Linear Regression model to predict house prices based on various housing features such as:

- Median Income
- House Age
- Average Rooms
- Average Bedrooms
- Population
- Average Occupancy
- Latitude
- Longitude

The project includes:

- Data preprocessing
- Exploratory Data Analysis (EDA)
- Model Training
- Model Evaluation
- Model Saving
- Streamlit Web Application
